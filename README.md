# Wall Loop 5080

A 3D configurator for a wall-mounted, custom water-cooled RTX 5080 PC on the CSFG "The Crow" plate.

- Pick real parts and see them in 3D, to scale, with their lights and the coolant in the tubes.
- Edit the hardline loop: every bend, fitting and straight is checked against published bending rules.
- Every part has its criteria: an impossible choice shows in red with the reason, a risky one in amber.
- Get a priced parts list grouped by shop, and a build code to share.

Parts are modelled from published dimensions; models marked E are estimates. The few AI images are captioned as AI renders, not photographs.

Static page served by GitHub Pages. Prices as seen on 1–2 October 2026 in France.
